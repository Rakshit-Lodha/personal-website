What's animating in the open state
  • Cover art — three blurred radial blobs drift and pulse on independent timers (11s, 14s, 18s) so the loop never feels obvious. Subtle vinyl ring + center dot adds character.
  • Lyrics — pure CSS karaoke. Container scrolls upward in 5 stops; each line has its own highlight keyframe synced to the scroll position. Active line goes white + scales 1.1x; others fade to ~32% opacity. Mask gradient softens the top/bottom edges.
  • Equalizer + progress bar — 5-bar EQ at the cover's bottom-left; progress bar fills over the same 20s cycle as the lyrics so they stay in sync visually in the mock.
For the real implementation
  • Lyric timing comes from a per-track timestamp array { t: 4.2, line: "..." }; the active line is computed from audio.currentTime.
  • The cover animation is identical in production — pure CSS, no JS cost.
  • Suno doesn't export synced lyrics, so you'll need to timestamp each line by hand once per song (5-10 min per track).
